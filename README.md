Comprehensive  
 End-to-End Repository Setup and Collaboration Exercise: 
• Install and configure Git (verify version, set username and email). 
• Initialise a local repository named unit1-comprehensive. 
• Create a README.md file with a project description written in Markdown. 
• Add and commit the file with a meaningful commit message. 
• Create a second file, make at least two commits, and use git log to display commit 
history. 
• Edit the file again and use git add -p to stage only part of the changes before 
committing. 
• Create a new branch called feature-demo, switch to it, and add a file demo.txt with at 
least one commit. 
• Merge feature-demo into main. If conflicts arise, demonstrate conflict resolution with 
screenshots. 
• Create a GitHub repository named unit1-comprehensive, connect it as a remote, and 
push your local repository to GitHub. 
• On GitHub, update the repository description, open an Issue requesting an update to 
the README, and resolve it by making a commit locally and pushing the changes. 
• Simulate collaboration: fork your own repository (from a second account or with a 
partner), clone it, create a new branch, and submit a Pull Request back to the main 
repository. 
• Demonstrate the difference between git fetch and git pull in keeping your local copy 
up to date. 
Prepare a detailed report containing: 
• CLI commands executed with screenshots. 
• Explanations of each step, including why each command was used. 
• Reflection on challenges faced and lessons learned from this end-to-end workflow.
